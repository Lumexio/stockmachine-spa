# stock-machine

[![AI Ready](https://img.shields.io/badge/AI--Ready-yes-brightgreen?style=flat)](https://github.com/johnpapa/ai-ready)

This template should help get you started developing with Vue 3 in Vite.

## Product claim baseline

- Appwrite provides account identity; StockMachine domain data is stored by the
  VPS backend in SQLite.
- Windows and Linux installers are published by `stockmachine-desktop` GitHub
  Releases, and Android APKs by `stockmachine-mobile` GitHub Releases.
- The site does not promise managed-cloud durability or managed backups.

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```

## Contributing

Fork the repository, create a focused branch, install with `npm ci`, and run `npm run build` before opening a pull request. Keep the site limited to marketing, pricing, and download content; preserve responsive behavior and the `CNAME`; and coordinate plan, release-link, or user-facing content changes with the relevant STOCKMACHINE repositories.
